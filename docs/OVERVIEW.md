# 离线研究总览

总览把已有工作台记录整理为一个本地页面，方便查看当前目标、下一步、任务和资料处理状态。页面来自已经保存的事件，不会自动判断研究进度，也不会自动生成新的研究结论。

## 生成与打开

先选择要查看的工作台目录，再运行：

```powershell
python -X utf8 "skills/research-workbench/scripts/workbench.py" overview --root "你的项目/research-workbench"
```

命令在该工作台内生成 `OVERVIEW.html`。双击文件即可用浏览器离线打开；已安装技能时，将命令里的脚本路径换成安装副本的实际路径。需要 Python 3.10+，无需额外 Python 包、服务器或浏览器插件。

在 Codex 中可以使用自然语言请求，例如：

```text
$research-workbench 更新项目总览，打开离线页面。
```

助手需要实际调用命令才会更新页面；这句话不建立后台定时任务。偏好聊天内摘要时，也可以直接说明，不必生成页面。

页面显示 UTC 生成时间，并标记为一次生成的**本地快照**。以后新增记录或修订任务时，已经打开的页面不会自动变化；重新运行命令，再刷新页面即可。

## 页面内容怎么理解

| 区域 | 展示的数据 | 边界 |
| --- | --- | --- |
| 当前目标与下一步 | 最新的当前有效 `checkpoint` 断点记录 | 没有断点时显示空状态，不推断目标 |
| 最近进展 | 最多 5 条当前有效的 `progress` 记录 | 不是完整工作日志；其他类型记录可查原工作台 |
| 任务分组 | 当前有效任务的待办、执行中、完成、取消、状态未指定 | 执行情况和研究确认状态分别显示 |
| 候选文献 | 候选队列的待筛选、保留、排除、已有笔记 | 每条对应一个候选 DOI，不是已读论文台账 |
| 已有文献笔记 | 当前有效 `paper` 笔记事件 | 数量不是去重论文数，也不是人工已读数 |

上方四个数字分别统计当前任务记录、未关闭任务记录、候选 DOI 条目和当前笔记事件。未关闭任务包括待办、执行中和状态未指定；完成与取消不计入。页面不统计全库文件数，不提供论文完成百分比。

候选被标为“已有笔记”时，仍显示原来的保留/排除筛选决定及理由。这个状态仅表示已有同 DOI 的当前笔记；即使笔记的 `reading_basis` 是全文，也不代表使用者已经人工阅读或确认。

作者、年份、刊物等没有记录的信息显示“未知”，不会根据标题补猜。卡片保留原事件和笔记入口；“依据与原记录”或“检索来源与原记录”可以展开核对时间、来源、筛选事件与引用。引用入口存在不等于证据已经核验。

默认卡片只展示当前有效版本。修订前的历史可以从“修订自历史版本”或原事件入口查看；显式关联若仍引用旧版本，会同时提示“历史目标”和最新版本入口，原关联不会被自动改写。

## 搜索与筛选

搜索支持中文，匹配页面卡片中的标题、摘要、作者、出处和依据文字。它只搜索本页展示的卡片，不能替代工作台 `search` 命令检索完整事件内容；最近进展只有 5 条，摘要也会截短。

可选择展示区域、任务执行情况、候选处理状态或研究确认状态；多个条件同时生效。选择任务执行情况时只显示任务，选择候选状态时只显示候选。候选条目没有独立的研究确认状态，研究状态筛选不会把候选视为已确认结论。条件相互冲突时可能没有结果，点击“清除筛选”即可恢复全部卡片。

筛选后的小组数字和“匹配卡片”数量会更新，上方四个快照数字仍对应生成时的全部当前记录。“匹配卡片”不是去重论文数：一个 DOI 可以同时在候选区域和已有笔记区域各有一张卡片。

## 保存与数据边界

- 总览按需生成，不加入默认 Markdown 重建流程。它不修改 `events/`、手写笔记或项目约定。
- 总览是派生文件，可重新生成；手写内容应放在 `PERSONAL_NOTES.md`。固定输出位置已有同名人工文件时，命令拒绝覆盖；工具生成的旧总览才可更新。
- `backup` 仍只备份已有受管理的原始记录和手写文件，不包含派生总览。恢复工作台后，需要查看总览时重新运行命令。
- 页面资源全部内嵌，打开页面与筛选时不请求网络、不上传资料。点击 HTTP(S) 证据或 DOI 链接时，浏览器才会打开外部页面。
- 标题、正文和其他资料字段都作为文字显示；网页限制可执行资源，并仅生成允许的 HTTP(S)、DOI 或工作台相对文件链接。不接受 `javascript:`、`data:`、任意 `file:` 绝对路径或越界本地链接。
- 总览可能包含未公开研究内容，应作为项目内的私有记录保管；工作台默认的 Git 忽略规则仍适用。

这项功能不替代真人 Codex 技能发现、跨对话续接或外部试用验收；页面也不会主动跟随原事件中的指令。

## 维护者验证

单独运行总览核心测试：

```powershell
python -X utf8 -m unittest discover -s tests -p test_overview.py -v
```

测试使用虚构工作台记录，覆盖空项目、中文目标与下一步、5 种任务状态、缺失可选元数据、被替代事件、历史关联目标、4 种候选状态及笔记来源。还会把 `</script>`、HTML 标签、事件处理属性和危险网址放入资料，按生成后的实际 HTML 标签结构检查，确认它们没有变成可执行内容；同时核对页内资源的 CSP 哈希及渲染前后原始文件一致性。

2026-10-09 本地核心测试为 **12 项通过**，环境为 Windows / Python 3.10.20。CLI 写入、安装副本与浏览器交互另由集成检查验证；远端 CI 是否通过，应以具体提交的 Actions 结果为准。
