# 社区启动与推广计划

## 当前发布口径

当前应称为 **pre-alpha open development**，可以邀请社区参与需求和架构讨论，但不能宣传为“已经可用的全能科研助手”。

推荐一句话介绍：

> Research Workbench Assistant is an open-source, local-first research memory system that helps AI-assisted research projects preserve progress, evidence, decisions, literature notes, and context across conversations.

中文介绍：

> 一个本地优先、证据可追溯的开源科研记忆系统，帮助长期使用 AI 的研究者跨对话保存进展、决策、问题、实验和文献知识。

## 第一阶段：公开设计

- 发布 GitHub 仓库；
- 明确 pre-alpha 状态；
- 开放 Feature Request，收集研究生真实痛点；
- 建立 v0.1 里程碑和可追踪 Issue；
- 优先邀请少量真实用户评审工作台结构。

## 第二阶段：可运行 MVP

- 提供 3 分钟以内的安装和初始化演示；
- 使用完全可公开的示例项目录制跨对话续接；
- 展示删除 Markdown 后从结构化记录重建；
- 发布第一个 alpha 版本；
- 在开发者和研究生社区发布演示，而不只发布项目介绍。

## 第三阶段：真实采用

- 收集匿名化使用反馈；
- 将常见问题转换为公开 Issue 和测试；
- 维护版本说明和迁移指南；
- 记录外部贡献、下游使用和可验证采用数据；
- 在证据充分后申请 Codex for Open Source。

## 推广时避免

- 把规划图当成功能演示；
- 使用真实论文、课题数据或私人日志截图；
- 宣称能够替代导师或自动保证研究正确；
- 购买 Star、批量发广告或夸大用户数量；
- 为了申请福利临时制造无实际价值的活动记录。
