# 产品范围

## 1. 产品定位

本项目是一个以“科研过程记忆”为核心的通用科研助手，而不是单次问答机器人或简单的论文摘要工具。

它将 AI 参与科研时产生的事实、任务、决策、问题、实验、文献和成果保存在用户本地，并在新对话开始时只恢复与当前任务相关的上下文。

## 2. 目标用户

- 刚开始建立科研工作方法的硕士生和博士生；
- 长期使用 ChatGPT、Codex 或其他 AI 助手开展科研的用户；
- 同时管理代码、数据、文献、实验、论文和汇报材料的科研人员；
- 希望保留本地记录、减少重复解释并降低 AI 状态混淆的用户。

## 3. v0.1 必须解决的问题

### 3.1 项目初始化

- 在任意科研项目中创建统一工作台；
- 读取用户配置，而不是固定项目路径、学科或 Python 环境；
- 创建适合人阅读的 Markdown 模板和机器读取的结构化记录。

### 3.2 跨对话续接

- 新对话默认读取简短断点；
- 根据用户问题检索相关事实、决策、问题和最近工作；
- 只有断点冲突、证据不足或形成正式成果时才执行完整审计。

### 3.3 科研进展记录

- 追加本轮实际完成的工作；
- 保存证据路径和验证结果；
- 更新当前状态、任务、决策和问题；
- 不因一次普通问答机械更新全部记录。

### 3.4 一致性检查

- 检查状态与日志是否冲突；
- 检查“已确认”条目是否缺少证据；
- 检查文件路径是否失效；
- 检查 Markdown 视图能否从结构化数据重新生成。

## 4. 后续版本

- **v0.2**：PDF/Zotero 导入、Markdown 与 JSON 笔记、哈希去重、修订链和索引。
- **v0.3**：文献元数据检索、候选筛选、开放全文发现和定期追踪。
- **v0.4**：论文—观点—方法—任务—实验记忆网络与语义检索。
- **v1.0**：稳定插件分发、跨平台安装、迁移工具、公开文档和社区贡献流程。

## 5. 明确不在 v0.1 中完成

- 自动完成整篇学位论文；
- 自动替用户决定研究路线；
- 自动把文献笔记标记为人工已读；
- 绕过版权、登录、验证码或付费墙；
- 在没有证据的情况下判断实验已经成功；
- 同时支持所有 AI 平台、所有数据库和所有学科专属字段。
