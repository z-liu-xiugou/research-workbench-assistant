# v0.1.0-alpha.9 — 科研记录、文献发现与本地图库预览版

Research Workbench Assistant is a local-first Codex Skill for graduate researchers. It keeps checkpoints, evidence-linked progress records, and versioned paper notes in the research project, so a new Codex chat can resume from saved context. This alpha adds Crossref discovery, project preferences, an offline overview, and an optional PDF figure archive. Independent end-to-end user acceptance in Codex remains pending; automated checks do not replace it.

本版汇集 alpha.1 发布以来的功能和修复，适合个人试用。标签为 `v0.1.0-alpha.9`，命令行显示 `0.1.0a9`，两者表示同一个版本。需要 Python 3.10+ 和可用的 Codex；核心工作台仅使用 Python 标准库，PDF 图库另装可选组件。

## 新增与改进

- **科研记录和新聊天续接**：保存目标、进度、问题、决策、实验与下一步；任务区分待办、执行中、完成和取消。续接先给简短断点和资料入口，按需读取完整记录。
- **文献笔记和候选检索**：笔记支持作者、年份、DOI、期刊或会议、标签，生成 Markdown 与 JSON。同 DOI 去重并保留修订历史；Crossref 主题和年份查询保存来源、检索批次及筛选理由，候选与实际笔记分别管理。
- **分页搜索与记录关联**：搜索先返回短摘要，可按类型、状态筛选，再用 `show --id` 查看准确版本。文献、任务和实验可显式关联，保存关联理由；查询会提示历史版本与当前版本。
- **备份和恢复**：备份受管理的配置、原始事件、手写笔记和项目约定；恢复到新目录并核对完整性，保留记录 ID 与修订历史，拒绝覆盖已有项目。
- **项目偏好与入门引导**：可跳过问题，把研究范围、语言、详略和资料位置放在项目自己的 `PROJECT_MANUAL.md`，无需修改已安装技能。未知内容保留“待定”，临时要求不会自动变成长期设置。
- **离线研究总览**：`overview` 按需生成 `OVERVIEW.html`，集中查看断点、任务、候选和已有笔记，支持搜索、筛选与来源导航。页面是生成时的快照，查看时无外部资源请求。
- **可选本地文献图库**：`figures extract/build/verify` 从指定本地 PDF 提取完整图候选，支持裁切修正、跨页拼接、PNG、缩略图、裁切 PDF、原页校对图和来源校验值；生成可双击打开的离线图片检索页。中文图意由人工或 Codex 阅读后填写，新图先保留待复核状态。
- **安装与维护**：安装使用临时目录和独占锁，中途失败可重试；`doctor` 只读检查安装与目录问题，默认隐藏个人路径。提供按准确提交打包的隔离安装检查，以及 Windows/Linux 自动检查流程。
- **证据与确认边界**：新记录使用 v2 证据规则；进行中或已确认状态要求可定位证据，已确认还需保存用户明确确认的出处。AI 建议、程序校验、人工复核与人工已读分别记录。

## 安装准确版本

以下为 PowerShell 命令。选择 Git 或 ZIP 其中一种方式；已有同名技能时，先按下一节备份并移出旧安装。

**通过 Git 安装**

```powershell
git clone --branch v0.1.0-alpha.9 --depth 1 https://github.com/z-liu-xiugou/research-workbench-assistant.git
cd research-workbench-assistant
python -X utf8 scripts/install.py
```

**通过本次 Release 的 ZIP 资产安装**

下载 `research-workbench-assistant-v0.1.0-alpha.9.zip` 和 `SHA256SUMS.txt` 到同一目录，先核对 ZIP 的 SHA-256 是否与清单一致：

```powershell
Get-FileHash -LiteralPath .\research-workbench-assistant-v0.1.0-alpha.9.zip -Algorithm SHA256
Get-Content -LiteralPath .\SHA256SUMS.txt -Encoding UTF8
Expand-Archive -LiteralPath .\research-workbench-assistant-v0.1.0-alpha.9.zip -DestinationPath .\research-workbench-assistant-v0.1.0-alpha.9
cd research-workbench-assistant-v0.1.0-alpha.9
python -X utf8 scripts/install.py
```

解压目标须是尚不存在的新目录。以上对应本次附带的源码 ZIP；若使用 GitHub 自动生成的 “Source code” 包，解压后进入包含 `scripts/install.py` 的源码目录再安装。

安装器将技能复制到用户的 `.agents/skills/research-workbench`，拒绝覆盖同名安装。Codex 未发现技能时重启 Codex，在自己的演示项目中输入：

```text
$research-workbench 请为这个项目初始化科研工作台。先了解研究目标，不要编造进展，也不要覆盖已有记录。
```

## 从旧版本升级

1. 先备份科研工作台和旧技能目录。已有 `backup` 命令可备份受管理记录；旧版没有该命令时，在无写入进程的情况下复制完整工作台。
2. 将旧 `research-workbench` 技能目录移到 Codex 技能扫描目录之外，再按上文安装准确版本。不要仅在扫描目录内改名，也不要直接覆盖旧安装。`git pull` 不会更新已安装的技能副本。
3. 运行实际使用的 `workbench.py --version`，应显示 `0.1.0a9`。先在工作台备份副本上运行新版 `audit`，按提示复核，再按需 `render` 重建生成视图。不要手动改写原始事件版本号。
4. 自编脚本若读取 `search` 或 `resume` 的输出，按下文调整后再用于原项目。回退技能源码不会同时回退工作台数据。

**备份范围需另行核对**：内置备份未加密，不包含原始论文、实验数据、自建文件、图库资产或原 PDF。这些资料及图库清单需另外完整备份；派生总览页面可在恢复后重新生成。

## 命令输出的兼容变化

- `search` 返回一个 JSON 对象，结果在 `items`，另含 `total`、`offset`、`limit`、`next_offset`；不再按旧数组或逐条完整事件格式读取。默认每页 10 条、最多 50 条，`--full` 也仅展开当前页。使用 `show --id` 读取指定记录的全文。
- `resume` 返回 JSON 读取计划，包含 `checkpoint` 等字段；不再按纯 Markdown 文本解析。本版还增加可选 `project_preferences` 项目档案导航，严格校验字段列表的调用者需允许该字段。
- 旧 v1 事件保留并可读取；`audit` 可能提示旧记录需要复核并返回非零状态。提示本身不表示数据损坏，也不表示程序已经迁移或确认这些记录。新增 v2 事件不保证旧工具能读取。

## 可选 PDF 组件

在解压或克隆的源码目录中安装锁定依赖：

```powershell
python -m pip install -r skills/research-workbench/requirements-figures.txt
```

本版使用 pdfplumber 0.11.10、pypdfium2 5.14.0、pypdf 6.21.2 和 Pillow 12.2.0；组件各自保留上游许可证。核心记录与续接功能不要求安装它们。具体范围、命令和许可见 [图库说明](https://github.com/z-liu-xiugou/research-workbench-assistant/blob/v0.1.0-alpha.9/docs/FIGURES.md) 与 [第三方许可说明](https://github.com/z-liu-xiugou/research-workbench-assistant/blob/v0.1.0-alpha.9/docs/THIRD_PARTY_NOTICES.md)。

## 预览版限制与真人验收

- 本版仍是 alpha，不承诺后续版本无需迁移。没有自动升级或回退、OCR、全文下载、自动全文理解、Zotero 同步、多人实时协作或自动推断的文献图谱。
- Crossref 一次只返回有限候选，不代表穷尽检索；生成笔记或图片说明不表示用户已读，也不证明科研结论。图库提取结果需要复核。
- 本地文件和离线页面不等于整个 Codex 工作流离线；使用 Codex 或外部检索工具时应按实际工具的数据范围处理研究资料。
- 多个生成视图不是一次不可分割的写入，异常中断后可能需要 `audit` 和 `render`。`doctor` 只给诊断建议，不自动修复，不证明 Codex 已加载技能或下一次写入一定成功。
- [#12](https://github.com/z-liu-xiugou/research-workbench-assistant/issues/12) 与 [#13](https://github.com/z-liu-xiugou/research-workbench-assistant/issues/13) 的首版功能已实现；已收到的使用建议不等于完整验收通过。
- [#9](https://github.com/z-liu-xiugou/research-workbench-assistant/issues/9) 仍待独立真人在准确版本上完成安装、自然语言记录、关闭旧聊天后新建聊天续接及备份恢复的逐步记录。自动测试、脚本返回续接计划和 AI 自测均不能替代。欢迎按 [试用清单](https://github.com/z-liu-xiugou/research-workbench-assistant/blob/v0.1.0-alpha.9/docs/USER_TRIAL.md) 提交脱敏结果。
