## 可用于 GitHub Release 的说明草稿

### v0.1.0-alpha.9 — 科研记录、文献发现与安装维护预览版

本版汇集 alpha.1 发布后主分支上的功能与修复，仍为面向个人试用的早期预览版。支持 Python 3.10+，核心脚本仅使用标准库。

**新增与改进**

- 科研任务可记录待办、执行中、完成和取消；新对话续接提供有限长度的摘要与记录入口。
- 文献可记录作者、年份、DOI、来源及标签；同 DOI 去重，保留修订历史。
- Crossref 在线主题/年份检索保留来源、批次和候选筛选理由，候选与实际阅读笔记分开。
- 本地搜索返回分页短摘要，支持类型/状态筛选，再通过 `show --id` 读取指定版本。
- 支持记录之间的显式关联、双向查询，以及工作台受管理记录的备份与新目录恢复。
- 新记录使用 v2 证据规则；进行中/已确认要求证据，已确认另需记录确认出处。
- 安装先复制到临时目录，使用独占锁防止安装器互相冲突，失败后清理临时状态。
- 自动检查采用固定提交的 Node 24 Actions 和 Ubuntu 24.04，并提供外部试用清单。
- `doctor` 检查技能文件、公开版本、静态目录权限、两类锁和工作台配置；默认隐藏个人路径，只给建议，不写入或修复。
- 分发包工具从指定 Git 提交生成 ZIP，用临时安装副本完成记录、修订、搜索、查看、续接及备份恢复；恢复前后原始事件字节一致。CI 在现有四组环境持续运行同一检查。
- Actions 版本更新由 Dependabot 每周提出 PR；保留完整 SHA 固定和人工审查，不自动合并。
- 项目约定模板保存目标、范围、偏好和资料位置，可跳过并保留待定；档案复用现有备份，与技能安装分离，旧配置与历史无需迁移。
- `overview` 生成无外部资源请求的离线快照，提供任务分组、候选及笔记筛选、来源链接；不自动更新、修改历史或将笔记视为人工已读。

**兼容性变化**

- `search` 由逐条完整事件输出变为 JSON 对象，结果放在 `items` 中；同时返回 `total`、`offset`、`limit`、`next_offset`。默认每页 10 条、最多 50 条，`--full` 也仅返回当前页。
- `resume` 返回含 `checkpoint` 的 JSON 读取计划，不能继续按纯 Markdown 解析。
- 本轮 `resume` 在原有读取计划中增加可选 `project_preferences` 档案导航；没有默认增加档案或事件库读取。严格按 JSON 键列表校验的调用者需允许此新增字段。
- 旧 v1 记录保留，不要求手动改版本号。`audit` 可能报告旧记录需复核并返回 1；这不是记录被自动迁移或损坏的证明。
- 新增字段或 v2 事件不保证旧程序可以读取。回退技能文件不等于回退工作台数据。

**升级方法**

1. 先单独备份科研工作台和已安装的技能。受管理记录可使用已有工具的 `backup`；若旧版没有该命令，在没有写入进程时复制完整工作台。论文和实验文件也需自行备份。
2. 取得目标版本源码；当前只能按主分支获取待发布代码。M03 发布后才可使用 `v0.1.0-alpha.9` 标签/下载包，不提前引用不存在的标签。
3. 将旧 `research-workbench` 技能目录移到技能扫描目录之外，再运行 `python -X utf8 scripts/install.py`。`git pull` 本身不会更新已安装的技能副本。
4. 运行所使用脚本的 `--version`，应输出 `0.1.0a9`；先在备份副本上用新版 `audit` 检查，再按需 `render` 重建派生视图。复核警告应按原因处理，不盲目重建原始事件。
5. 如有读取搜索结果或续接输出的自编脚本，按上面的接口变化调整。详细命令见 [安装与使用](GETTING_STARTED.md)。

**已知限制**

- 没有自动升级/回退、RIS/BibTeX 导入、无 DOI 自动去重、PDF 解析、全文下载或 Zotero 同步。
- `doctor` 的静态权限检查不能保证实际写入成功；不会判断锁是否已失效，不核验 Codex 是否加载技能、事件结构或科研结论。完整数据检查仍使用 `audit`。
- Crossref 单次只取有限数量结果，不代表完整检索；摘要和生成笔记不代表真人已读。
- 多个生成视图不是整体事务，写入中断后可能需要检查并重建；锁文件残留需先确认没有运行中的进程再处理。
- 备份不加密，只覆盖受管理文件；证据字段、校验和及程序测试不证明科研结论真实。
- #9 的独立用户 Codex 试用尚未完成。Linux/Windows 脚本测试不能替代真人技能发现和跨对话体验验收。
