# 文献图片功能

图库是随 `research-workbench` 技能安装的可选组件：从用户指定的本地 PDF 提取完整图候选，修正裁切，按文献归档，并生成可双击的离线检索页面。

完整输入格式、命令、核验状态和备份方式见[技能内使用说明](../skills/research-workbench/references/figures.md)。中文解释由人工或 Codex 阅读后填写；程序不自动翻译、生成论文理解或改绘曲线。结构检查、AI 复核、人工复核和整篇覆盖分别记录，不改变原有阅读状态。

基础工作台继续只需 Python 标准库。PDF 图片提取需另装锁定的可选组件；普通记录、搜索、续接和离线图库页面生成不强制安装这些依赖。

本功能迁移的是通用方法与界面，不包含原课题论文、真实图像、项目清单或历史审图记录。它不增加 [#9 首次使用验收](USER_TRIAL.md) 的最低关闭条件；图库测试也不能代替外部用户在 Codex 中完成试用。
