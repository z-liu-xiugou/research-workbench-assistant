## 4. 建议迁移方法

不要直接在私有副本中搜索替换课题名称。应先建立新的通用 Schema 和配置接口，再逐个迁移函数：

1. 文件哈希、路径安全和原子写入；
2. PDF 提取；
3. 结构化笔记校验和发布；
4. 文献索引；
5. 工作事件和状态重建；
6. Markdown 视图生成；
7. Zotero 与网络检索适配器；
8. 学科 profile。

每迁移一项，使用现有测试思想重新编写通用测试，不能直接依赖私有课题夹具。
