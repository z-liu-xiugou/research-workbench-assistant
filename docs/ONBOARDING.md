# 可跳过的入门引导与项目偏好

同一份通用技能可以服务不同项目。项目的范围、输出习惯和资料位置保存在各自工作台的 `PROJECT_MANUAL.md`，不需要修改安装的技能源码。

这是 #12 的第一版：提供固定章节模板和按需对话引导。没有新增偏好配置命令，也不修改配置 v1 或历史事件。

## 开始使用

创建新工作台后，`PROJECT_MANUAL.md` 带有“当前目标与阶段”“研究范围”“交互与输出偏好”“资料目录映射”“更新留痕”五个章节，空白字段写为“待定”。用户可以直接编辑，也可以对助手说：

> 帮我填写这个项目的约定。先只保存当前目标：整理资料；阶段：文献研究。其他都待定。

引导允许跳过、少填和稍后补充。还没定题也能记录进展和下一步，不要求先选择研究方法。旧工作台没有档案或缺少字段时，原有记录和续接仍可使用；助手只询问本次需要的缺项，不用新模板覆盖已有手写内容。

```powershell
python -X utf8 .\skills\research-workbench\scripts\workbench.py init --root .\research-workbench --name "虚构练习项目"
python -X utf8 .\skills\research-workbench\scripts\workbench.py resume --root .\research-workbench
```

`resume` 提供断点和项目档案读取入口，不会因为增加偏好模板而默认扫描全文献库。助手按当前任务读取适用的档案章节；切换项目时重新读取该项目的设置。

## 可以保存什么

| 内容 | 填写示例 | 未知时 |
| --- | --- | --- |
| 当前目标、研究阶段 | 整理资料 / 文献研究 | 待定 |
| 问题、对象与案例、时段 | 填用户明确提供的内容，附范围依据与确认状态 | 不替用户定题 |
| 输出语言、详略 | 中文 / 简洁；英文 / 详细 | 沿用现有行为 |
| 文献笔记模板、常用输出 | 来源—方法—局限；表格与 Markdown | 不绕过来源、局限等记录必填字段 |
| 图表偏好 | 聊天简图 / 本地总览 / 按需 | 结合本次请求 |
| 资料目录映射 | 项目内 `materials/literature`，待核对 | 不自动建目录或搜索 |

完整空白模板见 [项目约定模板](../skills/research-workbench/references/project-manual-template.md)，操作约定和两套虚构示例见 [入门引导](../skills/research-workbench/references/onboarding.md)。示例不代表真实课题或默认研究路线。

## 更新时保留已有内容

“这次写短一点”只改变本次回答。只有明确要求以后持续采用某个偏好，才保存到当前项目档案。助手先说明明确的字段差异，保留更新日期和对话出处，不把项目 A 的偏好带到项目 B。

修改研究范围时，先展示“原值 → 拟改值”、依据和拟保存状态，再由用户针对差异确认。助手建议、候选选题和待导师确认事项都保留原有身份；引导完成不代表范围或科研结论已经验证。

已有文件缺项时只补缺项，修改指定字段时保留其他手写内容。`PROJECT_MANUAL.md` 不是自动视图，`render` 不会替你更新或覆盖它。

## 接着做什么

- “继续上次工作。”
- “记一条进展：……”
- “找一下本地关于某关键词的资料。”
- “看看还有哪些待办。”
- “先跳过设置，只记录下一步。”
- “帮我画个项目情况图。”
- “显示今天的研究进度。”
- “更新项目总览。”

请求项目情况图或当天进度时，助手结合已保存的图表偏好和本次明确要求选择聊天简图或本地总览。明确说“更新项目总览”则直接运行 `overview --root`，生成本地 `OVERVIEW.html`。总览是生成时的快照，当前目标来自已记录 checkpoint；当天没有记录或没有断点时如实说明，不猜测。总览会读取工作台事件库，普通续接不默认生成。文件可能包含私有资料，详见 [项目总览说明](OVERVIEW.md)。

## 升级和备份

技能安装目录与项目目录分开。换用新安装副本时保留项目档案；安装器拒绝覆盖已有同名安装目录。`PROJECT_MANUAL.md` 已包含在 `backup` 的现有白名单中，恢复时保留文本，不增加新的项目配置文件。

```powershell
python -X utf8 .\skills\research-workbench\scripts\workbench.py backup --root .\research-workbench --output .\snapshot.json
python -X utf8 .\skills\research-workbench\scripts\workbench.py restore --input .\snapshot.json --root .\restored-workbench
```

备份未加密且可能包含私有研究记录；其他论文、数据和自建文件仍需单独备份。本版自动测试验证档案隔离、兼容性和备份恢复；真实 Codex 对话是否按新语言、详略和笔记模板输出，仍需用户端试用验收。脚本的 JSON 和自动视图格式保持既有规则。
