- Windows / Python 3.10.20：完整 141 项源码测试中 138 通过、3 项链接权限跳过。复核恢复后总览的内容断言后，14 项分发回归再次全部通过。

- 使用两个虚构项目检查偏好与记录隔离；旧配置和事件无需迁移，修改后的手写项目档案可按原字节恢复。新安装不会修改项目档案。

- 技能结构检查通过，公开文件扫描 0 命中，差异格式检查通过。远端 CI 记录按同一完整提交 SHA 核对，不用旧提交结果代替。

## 使用方式与后续

新项目可以说“初始化一个科研工作台，先跳过设置”，以后再补项目档案；已有项目保留手写约定。明确长期修改偏好时可以说“这个项目以后使用英文、简短回答”；本次任务的具体要求仍优先。

需要本地页面时说“更新项目总览”，或按 [总览命令](OVERVIEW.md) 生成 `OVERVIEW.html` 并双击打开。它是生成时的快照，记录改变后需重新生成；页面属于项目私有资料，备份原始记录后可重新生成。

首版采用人工可读的项目档案和已有记录结构，不增加第二套配置协议。候选筛选与笔记记录分别展示，不据此判定真人已读或研究完成。图谱、趋势图等后续增强未纳入本轮。

功能已推送主分支，仍为未发布 alpha.9 / CLI `0.1.0a9`。没有创建标签或 Release；`git pull` 不会更新已有的技能安装副本，换用新副本需遵循 [安装与升级说明](GETTING_STARTED.md)。#12/#13 保留开放供首版试用，#9 保留开放等待完整验收。
