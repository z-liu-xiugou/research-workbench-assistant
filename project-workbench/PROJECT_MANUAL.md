# 通用科研助手项目说明书

更新时间：2026-09-07

## 1. 项目定位

本项目开发一套面向研究生和科研人员的通用科研助手。核心任务是把 AI 参与的长期科研过程保存为本地、可追溯、可核验、可跨对话续接的记录。

## 2. 已确认目标

- 记录当前科研内容、主要进展和下一步；
- 在新对话中按需恢复科研记忆；
- 管理工作日志、任务、决策、问题、实验、材料和成果台账；
- 自动发现文献并维护候选队列；
- 生成 Markdown 和结构化 JSON 文献笔记；
- 建立论文、观点、方法和当前研究之间的记忆网络；
- 最终以独立开源项目向社区发布。

## 3. 固定边界

- 原有科研助手和原课题工作台不属于本项目的修改范围；
- 私有参考副本不属于公开仓库内容；
- 不公开论文全文、用户研究数据、个人路径和账户信息；
- 不绕过版权、登录、验证码或访问控制；
- 不把 AI 生成内容自动认定为事实、实验结果或人工已读；
- 没有证据时不得把计划功能写成已经实现。

## 4. 证据优先级

1. 用户在最新对话中明确确认的要求；
2. 当前仓库中的代码、测试和运行结果；
3. 当前项目结构化状态和工作日志；
4. 设计与规划文档；
5. AI 建议。

## 5. 开发路线

项目按科研记忆核心、文献笔记库、文献发现与记忆网络、社区分发四个主要版本推进，详细验收条件见 `docs/OPEN_SOURCE_ROADMAP.md`。

## 6. 状态规则

使用 `已确认`、`进行中`、`计划中`、`候选方案`、`待确认` 和 `AI建议`。每个“已确认”或“进行中”条目必须能指向文件、测试、运行结果或用户确认。
