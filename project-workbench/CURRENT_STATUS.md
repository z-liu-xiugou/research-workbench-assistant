# 当前项目状态

更新时间：2026-09-08

## 已实现

alpha.7 补齐 v0.1 验收缺口：配置/事件/记录 Schema，fact/artifact 类型，进行中与已确认的引用校验、明确确认出处，DECISIONS_AND_ISSUES 生成，resume 有界读取与触发路由，已知隐私模式扫描。测试与边界集中记录在 docs/ISSUE_ACCEPTANCE.md。

alpha.6 已内置 Crossref 联网检索及候选队列，按 DOI 去重并保存检索来源、时间和筛选理由。真实公开主题检索首次 3 篇、再次 0 篇新增/3 篇重复；候选不生成精读笔记。新增 16 项离线测试，本地共 58 通过、1 权限跳过。

alpha.5 实现文献/任务/实验等记录的显式关系存储、查询及导出。引用精确事件版本，旧目标更新不会静默改变关联。尚无自动推断或交互式图谱。alpha.4 远程 CI 已核实成功。

alpha.4 已实现 backup/restore；备份配置、事件、两个人工维护文档，恢复只到新目录。备份不加密，不包含用户论文及其他任意文件。原始 events 目录丢失会拒绝读取。

alpha.3 增加 task_state、tasks 筛选、TASKS.md，以及带原始事件链接的限长续接摘要；本地 25 项通过、1 项符号链接权限跳过。alpha.2 的 GitHub CI 已核实通过。

alpha.2 已补充文献元数据、DOI 归一化与重复入库保护，以及 PAPER_INDEX.md 当前文献目录。

首个可安装试用的本地 Codex Skill 与 Python 记录工具。使用独立 JSON 事件作为原始记录，自动生成工作台、分类台账和双格式文献笔记；支持追加修订、关键词检索与恢复。代码不依赖私有副本或第三方 Python 包。

## 验证边界

本地 Windows/Python 3.10 运行脚本及独立安装测试通过。符号链接测试可能因操作系统权限跳过；远端 CI 结果以 GitHub Actions 为准。Skill 静态校验通过不等于真实用户端对话验收。

## 计划中

其他来源检索、PDF 解析、无 DOI 去重、独立 DOI/撤稿状态核验、Zotero 接入、交互式文献图谱。#1–#6 按 alpha.7 的实际测试和远端 CI 证据逐项处理，不把上述未来能力算作已实现。

## 设计取舍

首版采用自包含 Skill + Python 标准库，不新增模型 API。每个事件单独原子保存；多个视图不是整体事务，失败后 render 重建。历史存储不是防篡改存储。人工自由笔记与自动视图分离。

## 安全

仅开发新开源仓库；私有副本不提交。安装器不覆盖同名技能，初始化不覆盖现有目录；所有示例虚构。
